# Sample documents (start small)

Use **tiny** text files while you learn chunk boundaries and token counts.

- **`tiny-tech-note.txt`** — Short synthetic note (safe to experiment with).

**Do not** start with a full manual PDF for Lab 02. After you are comfortable with estimates and chunk previews, move to the full pipeline in **[aws-pdf-rag-mr](https://github.com/rivadaviam/aws-pdf-rag-mr)** for PDF extraction and production chunking.
